# Japanese Learning RPG

A Pokémon-inspired educational RPG built in Godot using GDScript.

## Overview

This project combines JRPG-style exploration with educational gameplay to help players learn Japanese Hiragana through interactive battles.

Players explore an overworld, interact with trainers, and answer Japanese character questions during turn-based encounters. The project is being developed as both a game development learning exercise and a language-learning tool.

## Features

### Overworld

* Player movement and directional animations
* Camera-follow system
* TileMap-based world creation
* Environmental collision system
* NPC trainers
* Interactive game world
* Multi-scene architecture

### Battle System

* Quiz-based battle encounters
* Multiple trainer battles
* Hiragana recognition questions
* Dynamic answer generation
* Health point (HP) system
* Win/loss conditions
* Trainer progression tracking
* Scene transitions between exploration and battle
